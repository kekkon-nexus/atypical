---
title: Hooks
description: Running commit-lint as a commit-msg hook.
---

git passes the message file path to a `commit-msg` hook as its first
argument. A non-zero exit aborts the commit.

| Setup     | File                     | Contents              |
| --------- | ------------------------ | --------------------- |
| husky     | `.husky/commit-msg`      | `commit-lint -- "$1"` |
| Plain git | `.git/hooks/commit-msg`  | See below             |

```sh title=".git/hooks/commit-msg"
#!/bin/sh
commit-lint -- "$1"
```

A plain git hook must be executable and needs `commit-lint` on `PATH`.
With only the npm package installed, the command is
`npx commit-lint`. `.git/hooks` is not versioned, so each clone needs
the hook installed separately.

husky adds `node_modules/.bin` to the hook's `PATH`.
