Atypical is a set of tools that enforce conventions declared by the
repository. All tools read one file, `atypical.toml`. Each tool reads
only its own top-level section.

The only tool so far is `commit-lint`, which lints commit message
headers against the `[commit]` section.

```toml title="atypical.toml"
extends = "npm:@atypical/commit/conventional"

[[commit.slots]]
name = "keywords"
values = ["feat", "fix", "docs"]
```

This file extends the Conventional Commits preset and restricts the
`keywords` slot to three values. All other slots keep the preset's
definition.
