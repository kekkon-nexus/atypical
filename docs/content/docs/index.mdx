Atypical enforces conventions you declare, not ones it ships. Every tool
reads its own section of a single `atypical.toml`, found by walking up
from the working directory.

```toml title="atypical.toml"
extends = "npm:@atypical/commit/conventional"

[[commit.slots]]
name = "keywords"
values = ["feat", "fix", "docs"]
```

That file pulls in the Conventional Commits preset, then narrows its
keywords to three. Every other slot the preset declares stays as it was.

## Packages

| Package                                                                  | What it is                                                     |
| ------------------------------------------------------------------------ | -------------------------------------------------------------- |
| [`atypical-commit`](https://crates.io/crates/atypical-commit)            | The `commit-lint` binary and the commit header parser library  |
| [`@atypical/commit`](https://www.npmjs.com/package/@atypical/commit)     | `commit-lint` prebuilt for npm, plus the presets by name       |
| [`atypical-config`](https://crates.io/crates/atypical-config)            | Finds and loads `atypical.toml`, resolving `extends`           |
