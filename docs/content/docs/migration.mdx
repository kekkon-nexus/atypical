## From commitlint

| commitlint                                     | atypical                                         |
| ---------------------------------------------- | ------------------------------------------------ |
| `@commitlint/config-conventional`              | `extends = "npm:@atypical/commit/conventional"`  |
| `commitlint.config.*`                          | `atypical.toml`                                  |
| `commitlint --edit "$1"` in `.husky/commit-msg` | `commit-lint -- "$1"`                           |
| `commitlint --from <rev>`                      | `commit-lint --from <rev>`                       |

### Rules

`commit-lint` checks the header's shape against a grammar. It has no
other rules.

| commitlint                          | atypical                                                                 |
| ----------------------------------- | ------------------------------------------------------------------------ |
| `type-enum`                         | `values` on the `keywords` slot                                          |
| `type-empty`                        | `required = true` on the `keywords` slot                                 |
| `scope-enum`                        | `values` on the `scope` slot                                             |
| `scope-empty`                       | `required` on the `scope` slot                                           |
| `subject-empty`                     | Always enforced                                                          |
| `defaultIgnores`                    | [`default-ignores`](/docs/commit/default-ignores)                        |
| `ignores`                           | Not supported                                                            |
| Case, length, `body-*`, `footer-*`  | Not supported                                                            |

### Latency

`bun run bench` runs [hyperfine](https://github.com/sharkdp/hyperfine)
on one valid and one invalid header per tool.

| Command               | Mean wall time  |
| --------------------- | --------------- |
| `commit-lint` valid   | 1.3 ± 0.2 ms    |
| `commit-lint` invalid | 1.3 ± 0.3 ms    |
| `commitlint` valid    | 643.3 ± 60.1 ms |
| `commitlint` invalid  | 650.5 ± 46.9 ms |

| Footprint                                      | Size                          |
| ---------------------------------------------- | ----------------------------- |
| `commit-lint` release binary                   | 1.2 MB                        |
| `@commitlint/cli` with `config-conventional`   | 10 MB in 70 packages, plus Node |

Measured 2026-10-20 on an Intel Core i5-1135G7, Linux, rustc
1.101.0-nightly.

## From the fixed-layout keys

The fixed-layout keys of `[commit]` are removed and rejected as unknown
keys.

| Removed             | Replacement                                        |
| ------------------- | -------------------------------------------------- |
| `keywords`          | `values` of a `kind = "word"` slot                 |
| `modifiers`         | `values` of a `kind = "symbols"` slot              |
| `modifier-sequence` | The modifier slot's position in the list           |
| `separator`         | `values` of a `kind = "symbol"` slot               |
| `enclosures[]`      | One slot per enclosure, with `delimiters` and `values` |

```toml title="Before"
[commit]
keywords = ["feat", "fix"]
separator = ":"
```

```toml title="After"
[[commit.slots]]
name = "keywords"
kind = "word"
values = ["feat", "fix"]
required = true

[[commit.slots]]
name = "separator"
kind = "symbol"
values = [":"]
required = true
```
