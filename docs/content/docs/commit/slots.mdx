---
title: Slots
description: Declaring a commit header, one part at a time.
---

A header is a prefix of slots followed by a description:

```txt
feat(api)!: add an endpoint
└──┘└───┘│└ separator, then one space and the description
 │    │  └ modifiers
 │    └ scope
 └ keywords
```

The grammar is `[[commit.slots]]`, one entry per slot, in header order:

```toml title="atypical.toml"
[[commit.slots]]
name = "keywords"
kind = "word"
values = ["feat", "fix"]
required = true

[[commit.slots]]
name = "scope"
delimiters = ["(", ")"]

[[commit.slots]]
name = "separator"
kind = "symbol"
values = [":"]
required = true
```

This accepts `feat: x` and `fix(parser): x`, and rejects `chore: x`
and `feat x`.

## Fields

| Field        | Value                                                      |
| ------------ | ---------------------------------------------------------- |
| `name`       | Any string. Messages and [merging](/docs/configuration/merging) refer to it |
| `kind`       | `"word"`, `"symbols"` or `"symbol"`                        |
| `delimiters` | A pair of characters, such as `["(", ")"]`                 |
| `one-of`     | Options, each a slot of its own; see [One of](/docs/commit/one-of) |
| `values`     | `"any"` (the default), or a list of accepted spellings     |
| `required`   | `false` (the default) or `true`                            |
| `gap`        | `false` (the default), or `true` for one space after it; see [Spacing](/docs/commit/spacing) |
| `tight`      | `false` (the default), or `true` to never take a gap       |

A slot has exactly one of `kind`, `delimiters` or `one-of`.

## Kinds

| Kind      | Matches                                                         |
| --------- | --------------------------------------------------------------- |
| `word`    | A run of letters, digits and `_`, in any script                 |
| `symbols` | A run of visible characters that are not word characters        |
| `symbol`  | Exactly one such character                                      |

An unrestricted `symbols` run stops before any delimiter opener in the
grammar and before the separator that follows it. When that separator
is unrestricted too, the last symbol of the run is the separator.

## Delimited slots

A delimited slot holds a value between its two delimiters and is never
empty.

- With `values = "any"` it takes anything but its own delimiters,
  spaces included: `feat(a b): x` is valid.
- With a list it takes word characters and `-`, so a value like
  `t-rex` can be listed.

Delimited slots next to each other may each appear at most once, in
declaration order.

## Values

`values` restricts what a slot accepts to a closed list of spellings.
Every spelling must be matchable by the slot's kind, so a `symbol`
slot cannot list `::`. A bare slot tries longer spellings first, so
`!!` wins over `!` regardless of the order you list them in.

## Description

After the prefix comes exactly one space, then a description that is
not empty. Trailing whitespace is ignored. The description is not
otherwise checked.
