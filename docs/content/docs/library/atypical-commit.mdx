---
title: atypical-commit
description: The commit header parser behind commit-lint.
---

```sh
cargo add atypical-commit --no-default-features --features std
```

The parser is a [chumsky](https://docs.rs/chumsky) parser whose
grammar is data: `Tokens` lists the slots in header order and is
passed in as the parser's context.

```rust
use atypical_commit::{Extra, ExtraContext, Header, Tokens, header};
use chumsky::Parser;

let context = ExtraContext::new(&Tokens::default()).unwrap();
let parser = header().with_ctx(context);
let parsed = Parser::<'_, _, Header, Extra>::parse(&parser, "add: x");

let prefix = parsed.into_result().unwrap().prefix;

assert_eq!((prefix[0].name.as_str(), prefix[0].value), ("keywords", "add"));
```

## From a config

`config::CommitConfig` is the `[commit]` schema. It lowers into
`Tokens` with `try_from`, failing with `config::Invalid`.
`ExtraContext::new` then rejects
[ambiguous](/docs/commit/ambiguity) grammars with `Ambiguous`.

```rust
use atypical_commit::{ExtraContext, Tokens, config::{self, CommitConfig}};

let config: Option<CommitConfig> = atypical_config::load(path, config::SECTION)?;
let tokens = Tokens::try_from(&config.unwrap())?;
let context = ExtraContext::new(&tokens)?;
```

## Output

A `Header` is a `prefix` of `Part`s, one per slot present, and the
`description`. Each `Part` carries the slot's `name`, its `value` and
its `span` in the input. A delimited slot's value and span leave out
the delimiters.

`ignore::is_ignored` checks a header against the
[default ignores](/docs/commit/default-ignores).

## Features

| Feature | Default | Forwards                                          |
| ------- | ------- | ------------------------------------------------- |
| `std`   | yes     | `std` to the dependencies                         |
| `cli`   | yes     | clap's derive, help, usage and suggestions        |
| `color` | yes     | colored diagnostics and help                      |

They only forward dependency features; no code is gated behind them.

Full API on [docs.rs](https://docs.rs/atypical-commit).
