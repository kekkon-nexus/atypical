---
title: atypical-commit
description: The commit header parser behind commit-lint.
---

```sh
cargo add atypical-commit
```

The parser is built on [chumsky](https://docs.rs/chumsky). The grammar
is data: `Tokens` lists the slots in header order and is passed as the
parser's context.

```rust
use atypical_commit::{Extra, ExtraContext, Header, Tokens, header};
use chumsky::Parser;

let context = ExtraContext::new(&Tokens::default()).unwrap();
let parser = header().with_ctx(context);
let parsed = Parser::<'_, _, Header, Extra>::parse(&parser, "add: x");

let prefix = parsed.into_result().unwrap().prefix;

assert_eq!((prefix[0].name.as_str(), prefix[0].value), ("keywords", "add"));
```

## Pipeline

| Step                     | Function                         | Error              |
| ------------------------ | -------------------------------- | ------------------ |
| Load `[commit]`          | `atypical_config::load(path, config::SECTION)` | `atypical_config::Error` |
| Lower to a grammar       | `Tokens::try_from(&CommitConfig)` | `config::Invalid` |
| Validate the grammar     | `ExtraContext::new(&Tokens)`     | `Ambiguous`        |
| Parse a header           | `header().with_ctx(context)`     | chumsky `Rich` errors |
| Check the default ignores | `ignore::is_ignored(header)`    | none               |

## Output

| Type     | Fields                                                              |
| -------- | ------------------------------------------------------------------- |
| `Header` | `prefix`: the `Part`s present, in order; `description`              |
| `Part`   | `name`, `value`, `span`; delimited values and spans exclude the delimiters |

## Features

| Feature | Default | Forwards                                   |
| ------- | ------- | ------------------------------------------ |
| `std`   | Yes     | `std` to the dependencies                  |
| `cli`   | Yes     | clap's derive, help, usage and suggestions |
| `color` | Yes     | Colored diagnostics and help               |

The features only forward dependency features; no code is gated behind
them.

API reference: [docs.rs](https://docs.rs/atypical-commit).
