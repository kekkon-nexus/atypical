---
title: atypical-config
description: Discovery and loading of atypical.toml for Rust tools.
---

```sh
cargo add atypical-config
```

The crate has no section schema. A tool deserializes its own section
with serde, and inherits [discovery](/docs/configuration/discovery),
[`extends`](/docs/configuration/extends) and
[merging](/docs/configuration/merging).

```rust
#[derive(serde::Deserialize)]
struct Section {
    enabled: bool,
}

if let Some(path) = atypical_config::find(std::env::current_dir()?) {
    let section: Option<Section> = atypical_config::load(path, "tool")?;
}
```

| Item        | Behavior                                                                |
| ----------- | ----------------------------------------------------------------------- |
| `find`      | The nearest `atypical.toml` in a directory or its ancestors             |
| `load`      | Resolves `extends`, then deserializes one section; `None` when absent   |
| `resolve`   | Resolves `extends`; returns the merged `toml::Table`                    |
| `section`   | Deserializes one section of a document as written, without `extends`    |
| `FILE_NAME` | `"atypical.toml"`                                                       |
| `Error`     | Enum implementing `Display` and `std::error::Error`                     |

The [reserved keys](/docs/configuration/reserved-keys) apply to every
section.

API reference: [docs.rs](https://docs.rs/atypical-config).
