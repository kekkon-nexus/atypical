The files in
[`presets/`](https://github.com/kekkon-nexus/atypical/tree/main/presets)
are the only definitions. A preset is an ordinary `atypical.toml`
fragment, so anything it declares can be
[overridden](/docs/presets/customizing).

## Using one

With the npm package installed, extend a preset by name:

```toml title="atypical.toml"
extends = "npm:@atypical/commit/conventional"
```

Without npm, copy the file into your repository and extend it by path:

```toml title="atypical.toml"
extends = "conventional.toml"
```

Every preset turns on the [default ignores](/docs/commit/default-ignores).
