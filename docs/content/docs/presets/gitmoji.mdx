---
title: Gitmoji
description: "An emoji or :shortcode: intention, alone or in front of another preset."
---

```toml
extends = "npm:@atypical/commit/gitmoji"
```

| Slot        | Shape                                           | Required        |
| ----------- | ----------------------------------------------- | --------------- |
| `intention` | One of `emoji` (`symbols`) or `shortcode` (`: :`), followed by a [gap](/docs/commit/spacing) | yes |
| `scope`     | `( )`, anything                                 | no              |
| `separator` | `symbol` `:`, [tight](/docs/commit/spacing)     | no              |

## Examples

| Header                     | Result                                       |
| -------------------------- | -------------------------------------------- |
| `✨ Add a feature`         | Valid                                        |
| `:sparkles: Add a feature` | Valid                                        |
| `🐛 (auth): Fix a bug`     | Valid                                        |
| `✨: Add a feature`        | Valid                                        |
| `:t-rex: Add old code`     | Valid                                        |
| `feat: no intention`       | Invalid: no emoji or shortcode               |
| `✨:bug: both forms`       | Invalid: one form only                       |
| `:bogus: x`                | Invalid: unknown shortcode                   |
| `✨(auth): x`              | Invalid: the scope needs the space           |

## On top of another preset

Layered after another preset, gitmoji puts a required emoji in front
of its header:

```toml
extends = ["npm:@atypical/commit/conventional", "npm:@atypical/commit/gitmoji"]
```

This accepts `✨ feat(api): add an endpoint` and rejects
`feat(api): no emoji`. Keep the base first; see
[Merging](/docs/configuration/merging#order-in-extends-matters).

## Variation selectors

Some emoji are written with an invisible variation selector, such as
`⚡️` (U+26A1 U+FE0F). The preset lists them as the gitmoji catalogue
does, and the bare form without the selector (`⚡`) is not matched.

## Where it comes from

The preset is generated by
[`scripts/gitmoji.ts`](https://github.com/kekkon-nexus/atypical/blob/main/scripts/gitmoji.ts)
from the [gitmoji API](https://gitmoji.dev/api/gitmojis). Shortcodes
with characters a delimited slot cannot read are dropped, keeping their
emoji.
